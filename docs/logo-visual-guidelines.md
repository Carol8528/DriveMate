# DriveMate Logo 视觉规范

版本：V1.0  
适用范围：DriveMate 车载 HMI、演示材料、产品文档与数字媒体  
基准图稿：`assets/figma-hmi/drivemate-logo.png`

## 1. 品牌识别概念

DriveMate 标志由“兔子伙伴”与“方向盘”组合构成：

- 兔子传达亲和、灵敏、陪伴感，对应智能座舱中的自然交互与主动服务；
- 方向盘明确汽车与驾驶场景，建立产品类别识别；
- 单眼眨眼、腮红和圆润轮廓降低技术距离感，体现“可靠但不冰冷”的智能出行伙伴；
- 蓝色承担科技、可信赖与行驶安全的主感知，粉色只作为情感化点缀。

品牌气质关键词：`智能`、`可靠`、`亲和`、`轻盈`、`陪伴`。

## 2. 标志标准形态

### 2.1 图形标志

当前图稿为独立图形标志，不包含固定字标。兔子头部、耳朵、方向盘、面部表情及蓝色外轮廓构成不可拆分的完整图形。

使用时必须：

- 保持 1:1 原始比例；
- 等比缩放，不拉伸、不压扁、不旋转；
- 保留完整耳尖、方向盘外圈及两侧手部；
- 不单独抽取兔耳、表情或方向盘作为正式品牌标志。

### 2.2 品牌组合

产品界面采用“图形标志 + DriveMate”横向组合：

- 图形在左，品牌名在右；
- 图形高度为 `1H`，文字视觉高度约为 `0.40H–0.46H`；
- 图形与文字间距为 `0.25H`；
- 英文名称固定写作 `DriveMate`，不得写成 `Drivemate`、`Drive Mate` 或全大写；
- 字标尚无专用字体文件时，界面内沿用项目 UI 字体，字重 `700–750`，不得擅自仿制手写字标。

当前 HMI 推荐值：图形 `32 × 32 px`，间距 `8 px`，品牌文字 `14 px / 700–750`。

## 3. 标准色

当前标志包含渐变、描边和高光。以下色值为从现有栅格图稿提取并归一后的工程建议值，并非原始矢量设计色票；后续取得源设计文件时应重新校准。

| 角色 | HEX | RGB | 使用说明 |
| --- | --- | --- | --- |
| 品牌蓝 Brand Blue | `#4090C8` | `64, 144, 200` | 方向盘与主要外轮廓的代表色 |
| 深海蓝 Deep Blue | `#075394` | `7, 83, 148` | 眼睛、表情与深色强调，不大面积铺底 |
| 晴空蓝 Sky Blue | `#B0D8F0` | `176, 216, 240` | 方向盘内侧与高光区域 |
| 伙伴粉 Mate Pink | `#F6A1B0` | `246, 161, 176` | 耳内、鼻尖、腮红，仅作辅助点缀 |
| 兔白 Bunny White | `#FFFFFF` | `255, 255, 255` | 兔子主体和留白 |
| 墨蓝文字 Ink Blue | `#203047` | `32, 48, 71` | 与图形组合的品牌名及正文 |

建议数字界面变量：

```css
:root {
  --brand-logo-blue: #4090c8;
  --brand-logo-blue-deep: #075394;
  --brand-logo-blue-light: #b0d8f0;
  --brand-logo-pink: #f6a1b0;
  --brand-logo-white: #ffffff;
  --brand-wordmark: #203047;
}
```

标志自身的蓝色不等同于界面交互强调色 `--accent`。按钮、焦点和状态色继续服从产品 UI 设计令牌，不因 Logo 取色而整体替换。

## 4. 保护区

以图形整体高度定义为 `H`，以方向盘外圈蓝色描边的视觉厚度定义为 `x`。

- 标准保护区：标志四周至少保留 `0.25H`；
- 紧凑 HMI 顶栏：最低不得小于 `0.20H`，32 px 图形对应至少 6.4 px，工程取整为 `8 px`；
- 标志与卡片边缘、分割线、按钮、状态点及其他图标均不得进入保护区；
- 保护区只用于留白，不放置装饰线、发光、角标或文字。

当图形与 DriveMate 组成横向组合时，以整个组合外接矩形计算外围保护区。

## 5. 尺寸规范

| 场景 | 推荐尺寸 | 最小尺寸 | 备注 |
| --- | ---: | ---: | --- |
| HMI 顶栏 | `32 px` | `28 px` | 当前项目标准用法 |
| Agent 头像 | `32–40 px` | `28 px` | 必须使用透明、紧裁切版本 |
| 网站页签 / App 小图标 | 专用简化稿 | `16 px` | 不直接缩小当前复杂图稿 |
| 演示文稿页眉 | `40–56 px` | `32 px` | 与标题保持保护区 |
| 印刷物 | 按比例 | `8 mm` | 小尺寸前应打样检查表情清晰度 |

小于 `28 px` 时，耳内渐变、腮红、胡须和眨眼容易粘连或丢失。若必须用于 16–24 px 场景，应另行绘制简化版图标，不能通过锐化当前 PNG 代替。

## 6. 背景与版本

### 6.1 首选背景

- 首选纯白或低对比度浅色背景；
- 可用于浅蓝玻璃卡片，但标志外围必须保持清晰、完整；
- 深色背景上使用时，优先使用带透明通道的标准彩色版，并检查白色兔身与蓝色外轮廓均可辨识；
- 图片、地图或动态道路画面上必须先加单色承载底或独立卡片，不直接悬浮在复杂背景上。

### 6.2 单色版本

正式交付应补充以下版本：

- 全彩透明版：默认数字场景；
- 深蓝单色版：单色印刷、蚀刻或低成本制作；
- 反白版：仅用于深色纯色背景；
- 简化小图标版：16–24 px 场景。

禁止用 CSS 滤镜临时生成单色版或反白版，以免粉色、白色与轮廓层级失真。

## 7. 禁止用法

- 禁止非等比缩放、倾斜、镜像或旋转；
- 禁止改变兔耳、表情、腮红、方向盘之间的位置关系；
- 禁止替换为未定义的高饱和色、彩虹渐变或界面状态色；
- 禁止添加粗描边、重阴影、霓虹发光、立体挤压或外包围圆；
- 禁止裁切耳尖、方向盘或两侧手部；
- 禁止在低对比度、强纹理或高亮动态画面上直接使用；
- 禁止在 Logo 内叠加版本号、功能角标、认证标记或宣传语；
- 禁止把当前图片中的灰白棋盘格当作透明背景使用。

## 8. 当前源文件审计

当前 `drivemate-logo.png` 的技术状态：

| 检查项 | 结果 | 结论 |
| --- | --- | --- |
| 像素尺寸 | `1254 × 1254 px` | 满足常规屏幕展示，但不是矢量母版 |
| 色彩模式 | `RGB` | 可用于屏幕，不包含 Alpha 通道 |
| 透明背景 | 无 | 灰白棋盘格已烘焙在图片中 |
| 构图 | 1:1 居中图形 | 适合方形头像与图标容器 |
| 视觉细节 | 渐变、柔光、细描边较多 | 小尺寸识别存在衰减风险 |

因此，当前文件只能视为视觉参考稿，不应作为正式透明 Logo 母版。尤其在 HMI 顶栏和 Agent 头像中直接使用时，棋盘格会被显示出来。

## 9. 标准资产交付清单

正式品牌资产包应只保留一套最新母版，并包含：

```text
assets/brand/
├─ drivemate-logo-master.svg
├─ drivemate-logo-color.svg
├─ drivemate-logo-color.png        # 透明背景，建议 1024 × 1024
├─ drivemate-logo-mono-blue.svg
├─ drivemate-logo-reverse-white.svg
├─ drivemate-icon-small.svg         # 16–24 px 简化版
└─ README.md                         # 版本、色值与导出说明
```

导出要求：

- SVG 保留正确 `viewBox`，轮廓闭合，无外链字体与位图背景；
- PNG 使用 sRGB、透明通道和紧凑边界，不带棋盘格；
- 各版本保持相同视觉中心与外接比例；
- 文件名不使用 `final`、`new`、`最新版` 等不可追踪字样；
- 新母版通过验收后，应替换项目引用并删除冲突旧稿，避免新旧版本并存。

## 10. HMI 落地规则

- 顶栏固定使用 `32 × 32 px` 图形、`8 px` 图文间距；
- Logo 只承担品牌识别，不用于在线、告警、疲劳或接管等状态表达；
- 日间与夜间主题保持同一标志色彩，不随主题强调色切换；
- 可使用轻量投影增强浅色玻璃背景上的边界，建议不超过 `0 4px 8px rgba(49, 91, 178, 0.16)`；
- 替换透明母版后，应在 `1280 × 720` 与 `1366 × 768` 两种视口中检查清晰度、保护区、对齐和背景对比度；
- Agent 头像与顶栏标志应引用同一正式资产，不维护两套近似图。

## 11. 验收标准

标志交付或界面上线前，至少确认：

1. 文件无棋盘格、白边、脏像素或意外背景；
2. 图形比例为 1:1，视觉中心无偏移；
3. 32 px 下耳朵、眼睛、嘴部和方向盘仍可辨认；
4. 四周保护区符合标准，未与文字或控件拥挤；
5. 日间、夜间和图片背景上的对比度均通过人工视觉检查；
6. 品牌名称拼写统一为 `DriveMate`；
7. 项目中不存在冲突的旧 Logo 引用或重复资产。
