# DriveMate 数据来源与合规说明

> 版本：V8｜更新日期：2026-09-03｜适用范围：GOAI 复赛提交版、现场演示及本地测试

## 1. 说明目的与适用边界

本说明用于披露 DriveMate 当前版本涉及的数据类型、来源、授权状态、脱敏方式、隐私保护措施、使用边界、行业风险和合规约束。

当前版本属于赛事演示与技术验证系统，不是量产车载系统、自动驾驶控制系统、医疗器械、法律服务、保险定损系统或政府主管部门业务系统。项目展示的安全建议、路线规划、车辆状态、风险分级、工具回执和客服流程主要用于验证“理解需求—生成方案—确认高风险动作—执行—审计”的产品与技术闭环，不应被解释为已经完成真实道路、量产车辆或商业运营环境的合规准入。

## 3. 脱敏与隐私保护措施

当前版本采取或要求采取以下措施：

1. **数据最小化**：只收集完成当前交互、安全判断、工具执行和审计所必需的数据，不默认采集人脸原图、声纹、通讯录、证件、支付信息、完整轨迹或真实车辆标识。
2. **模拟数据明示**：演示传感器、车辆和订单状态必须标记为模拟，不以演示样例冒充真实采集或量产数据。
3. **去标识化**：使用随机 Session ID、Run ID、回执 ID 和工单 ID；测试数据使用虚构身份、地点和事件。需要关联真实主体时，应另行采用不可逆哈希、令牌化或受控映射表，并与业务数据分开保存。
4. **敏感字段控制**：正式接入前应建立字段清单和敏感级别，对姓名、手机号、车牌、VIN、精确位置、连续轨迹、音视频、生物识别和健康信息执行遮蔽、截断、泛化或删除。仅替换姓名不足以完成脱敏。
5. **本地优先与传输收敛**：默认流程可在本地运行；启用外部模型、CRM、地图、充电或车辆服务时，仅传输完成该步骤所需字段，并使用加密通道、鉴权和接口白名单。
6. **凭据隔离**：API Token、模型密钥和 CRM 密钥只通过环境变量或运行时一次性令牌提供，不写入源码、样例、截图、审计导出或公开仓库；已暴露的历史密钥必须撤销和轮换。
7. **访问与导出控制**：当前 REST API 和模拟器要求 Bearer Token；完整审计链只向持有有效本地 API 令牌的客户端提供。生产化还需增加用户/角色权限、最小权限、导出审批、访问日志和异常告警。
8. **保存期限与删除**：本地数据库属于演示运行数据，不提交版本库。正式试点前必须为各类数据设定明确保存期限、自动清理、备份删除和用户权利响应流程；不得以“审计需要”为由无限期保存全部原始内容。
9. **生命周期治理**：真实数据接入前应完成目的评估、数据盘点、授权核验和安全评估；使用中进行质量、权限和异常监控；用途结束后及时删除或不可逆匿名化。

脱敏后的数据如果仍可通过轨迹、时间、车辆、订单或其他数据组合重新识别个人，仍应按个人信息或敏感数据进行保护，不得因删除单一直接标识符而降低保护等级。

## 4. 数据使用边界与合规约束

- 仅将数据用于用户已知且合理预期的当前服务、必要的安全处置、故障排查和受控审计；用途发生实质变化时，应重新告知并取得相应授权。
- 不得将交互、位置、车辆状态、健康线索、未成年人信息或工单数据擅自用于广告、用户画像、保险定价、信用评价、劳动管理或其他自动化重大决定。
- 不得抓取、购买、拼接或导入来源不明的数据；真实道路、车辆、地图、订单、充电、客服及模型数据接入前，应核验数据提供方身份、处理权限、接口条款、质量责任和退出/删除机制。
- 涉及儿童、健康、生物识别、精确位置、连续轨迹、车辆控制等高敏感或高风险数据时，应采用更严格的必要性判断、单独授权、权限隔离、审计和人工复核；不满足条件时停止采集或降级为不含敏感数据的服务。
- 不得通过外部模型或日志系统发送访问密钥、完整个人档案、与任务无关的上下文或未经授权的第三方数据。
- 用户撤回授权、授权到期、处理目的完成、来源方提出合法限制或发现数据来源不合规时，应停止相关处理，并按适用要求删除、匿名化或隔离数据。
- 赛事演示结果、模拟器性能、样例准确率和本地审计覆盖仅代表当前受控环境，不得外推为量产安全指标、自动驾驶能力、医疗效果、法律结论或商业服务承诺。
- 在真实用户试点、公开发布或商业化前，项目方应结合部署地区和具体业务场景完成适用法律法规、行业规范、车辆与道路测试要求、网络与数据安全、个人信息保护、知识产权及供应商合同的专项评估。本说明本身不等于取得行政许可、行业认证或法律合规意见。

## 5. 高风险行业与场景风险提示

DriveMate 涉及汽车出行、道路交通、辅助驾驶、车辆控制、紧急救援、健康线索、儿童乘车、位置服务、保险/事故责任等高风险场景。相关数据可能存在延迟、缺失、误报、误识别、过期、地域差异或模拟与真实环境不一致，模型和规则也可能产生错误建议。

因此：

- **驾驶与车辆控制**：系统不替代驾驶员持续观察、依法驾驶和及时接管，也不替代车辆厂商的正式操作说明、诊断结果和道路救援意见。任何影响路线、订单、车辆或外部系统状态的高风险操作，必须经过权限校验、明确展示和用户确认；紧急情况下以现场安全、车辆警示、道路管理和紧急服务指引为先。
- **自动驾驶与 Robotaxi**：系统不替代自动驾驶安全员、运营人员、远程客服、车辆运营机构或交通主管部门的最终判断，不得单独作为车辆放行、接管、停运、事故处置或运营调度依据。
- **医疗与人身安全**：疲劳、失去意识、身体不适等判断仅为风险提示，不构成诊断、分诊或治疗建议。出现胸痛、呼吸困难、失去意识、严重外伤等情况时，应立即联系当地急救机构并服从专业人员指导。
- **法律、交管、保险与责任认定**：法规、处罚、事故责任和理赔具有地域性、时效性和事实依赖，系统不提供正式法律意见，也不替代律师、交警、保险机构、司法机关或主管部门的认定。
- **儿童与特殊人群**：儿童约束系统、座椅安装和应急处置应以产品说明、车型手册和当地强制规定为准；系统不替代监护人、医护人员或应急机构的判断。
- **地图、路线与充电**：路线、道路状态、充电站位置和可用性可能不实时或不完整，应以具备相应资质的服务商、现场标识和运营方最新信息为准。

## 6. 不替代专业决策的明确声明

本系统及其生成内容仅用于辅助理解、信息组织、方案提示、演示编排和受控流程验证，**不构成专业意见、法定结论、行政许可、产品认证、安全保证或自动执行授权**。

在汽车与自动驾驶、道路交通、医疗急救、法律合规、事故责任、保险理赔、未成年人保护、网络安全、数据治理等高风险行业或场景中，DriveMate **不得替代具备相应资质的专业人员、车辆或平台运营机构、医疗机构、保险机构、司法机关、应急机构或政府主管部门的最终判断和正式决定**。用户和部署方应根据实时现场情况、有效法规、正式文件和有权机构指令进行复核；当系统建议与专业人员、运营机构或主管部门指令不一致时，以后者的正式判断为准。

## 7. 上线、试点或公开发布前的合规门槛

在从赛事演示进入真实用户试点或商业部署前，至少应完成：

1. 建立数据目录，逐项记录数据字段、来源主体、授权凭证、处理目的、保存期限、接收方和删除机制；
2. 对真实车辆、地图、订单、位置、语音、DMS、健康线索、未成年人及客服数据分别完成必要性与风险评估；
3. 完成用户隐私告知、同意/撤回、查询、更正、删除、投诉和未成年人监护人授权流程；
4. 与外部模型、云服务、地图、CRM、车企及运营平台明确数据处理角色、用途限制、安全责任、留存训练、地域与退出安排；
5. 完成字段级脱敏、传输与存储加密、密钥管理、权限分级、审计告警、备份恢复和安全事件处置；
6. 核验知识库、代码、字体、图片、地图和品牌素材的许可证及授权证据；
7. 对高风险建议和动作执行开展专业评审、真实环境验证、故障注入、人工兜底和停止机制测试；
8. 由项目部署方的法务、隐私、安全、业务及相关行业专业人员共同审查，并根据适用地区要求取得必要许可、备案、认证或主管部门意见。

未完成上述事项前，系统应保持在受控演示或内部测试范围，不接入未经授权的真实个人、车辆、订单、医疗或生产运营数据。
